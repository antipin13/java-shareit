# ShareIt - Сервис для шеринга вещей

Многомодульное веб-приложение, позволяющее пользователям брать и сдавать вещи в аренду.

## О проекте

ShareIt - это платформа для совместного использования вещей, где пользователи могут предлагать свои вещи в аренду, находить нужные предметы и оставлять отзывы о качестве обслуживания.

## Основная функциональность

### Модуль пользователей
- Создание пользователей
- Обновление пользователей
- Удаление пользователей

### Модуль объявлений
- Создание и редактирование объявлений о вещах для аренды
- Поиск и фильтрация объявлений

### Модуль аренды
- Система бронирования вещей
- Подтверждение запросов на аренду

### Модуль отзывов
- Система комментариев

## 🛠 Технологический стек

### Backend
- **Java** - основной язык разработки
- **Spring Boot** - фреймворк для создания приложения
- **Spring MVC** - для построения REST API
- **Hibernate** - ORM для работы с базой данных
- **PostgreSQL** - реляционная база данных

### Инструменты разработки
- **Maven** - система сборки проекта
- **JUnit** - модульное тестирование
- **Mockito** - создание мок-объектов для тестирования
- **Postman** - тестирование API endpoints

### Архитектура
- **REST API** - архитектурный стиль для веб-сервисов
- **Многомодульная структура** - разделение на логические компоненты
